# Blue Balls of SPLORR!!

Keep them up. Don't let go.

Tap the blue balls to bop them back into the air. More keep coming. When one touches the floor, it's over; the score is how long you lasted.

A browser game in Odin (compiled to `js_wasm32`) by TheGrumpyGameDev, made with an AI agent (Claude Code). Font m5x7 by Daniel Linssen (CC0).

```bash
tools/test.sh
tools/build.sh
python3 -m http.server -d build/web 8053
```
